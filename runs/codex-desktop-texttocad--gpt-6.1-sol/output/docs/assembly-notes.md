Supplier-readable schematic is [fab/schematic.pdf](../fab/schematic.pdf).

Reconcile [filled-capped-hole-schedule.csv](../fab/drill/filled-capped-hole-schedule.csv) with the final drill data: **322 routing vias + twelve U6 0.30 mm thermal PTH features = 334 resin-filled/copper-capped holes**. Total PTH is **374**, comprising the 334 filled/capped features and **40 open component lead/shell holes**. Total NPTH is **7**, unplated and unfilled. Fill/cap every routing via and all twelve module thermal holes, never component lead/shell holes. The final schedule and drill classification govern processing.

Quote and inspect the corrected requested nominal stackup in the fabrication notes: ENIG, outer 35 µm / inner 17.5 µm copper, dielectric 0.120/1.255/0.120 mm, copper/dielectric total 1.600 mm excluding nominal 0.010 mm mask each side; green mask and white silkscreen. Supplier must confirm actual materials/cured thickness, not assume a default stock construction or controlled-impedance qualification. Supplier assembly drawings include [assembly-orientation.pdf](../fab/assembly/assembly-orientation.pdf) and [top-assembly-kicad.pdf](../fab/assembly/top-assembly-kicad.pdf).

Check pin1 markings for U1–U10, flash/PSRAM package widths, RNM pads9/10/11, module orientation, LED markings and every connector before reflow. Derive a profile compatible with the most restrictive part, including Hirose; check actual module/LED moisture and reel handling labels. Hidden QFN/module solder joints require suitable inspection, with X-ray where needed. Verify THT joints on the underside after SMT assembly. The package is for prototype first articles, not mass-production approval.

All routing vias and radio thermal via holes require resin fill/copper cap before assembly; see fabrication notes. This avoids paste loss through via-in-pad. Do not fill/cap connector lead holes. Wash/flux-clean compatibility must follow the actual component instructions, especially the card socket and high-impedance ADC/TS nodes.

Primary electrical evidence is linked in `research.md`; exact L1 family confirmation is [Coilcraft XAL40xx Document806](https://www.coilcraft.com/getmedia/6adcb47d-8b55-416c-976e-1e22e0d2848c/xal4000.pdf).
